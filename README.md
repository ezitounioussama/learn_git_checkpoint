# Learn Git — Workflow Checkpoint

The basic Git workflow, done step by step and captured as evidence: create a repository, stage a
file, commit it, read the log, add a second file, remove the first, and push. What is worth
looking at is not the files — `fourth.txt` is one line — but the sequence.

The 14 screenshots in [`screenshots/`](screenshots/) are numbered in the order the commands were
run, from `mkdir learn_git` through `git init`, `git add`, `git commit`, `git log`, `git rm` and
the push. The commit history in this repository is the same story told by Git itself.
